# GTA V Mod Installer

Настольное приложение для Windows, которое устанавливает моды GTA V из папок, архивов и каталога GTA5-Mods.com, раскладывает файлы по нужным папкам игры, находит зависимости и умеет полностью откатывать установку.

## Возможности

- **Папка или архив.** Перетащите папку мода или архив в окно. Архивы распаковываются автоматически, включая ZIP, RAR, 7Z, TAR/GZ/BZ2/XZ и OIV.
- **Вложенные архивы.** Если внутри мода лежит ещё один архив, он тоже будет распакован и учтён.
- **Правильные папки.** ASI-файлы ставятся в корень игры, SHVDN-скрипты — в `scripts` с сохранением папки мода (`scripts/SinglePlayerApartment/settings.cfg`). Готовые структуры `mods`, `lml`, `scripts` и `dlcpacks` сохраняются, DLC и RPF определяются отдельно.
- **Зависимости.** Установщик ищет Script Hook V, Script Hook V .NET, LemonUI, NativeUI, Lua Plugin, Heap Adjuster и Packfile Limit Adjuster по файлам, README и описанию мода. Компоненты скачиваются с официальных источников (dev-c.com, GitHub, GTA5-Mods). Если после установки чего-то не хватает, приложение предложит доустановить зависимости.
- **Онлайн-каталог.** Популярные и новые моды, поиск, карточка мода с описанием, скриншотами и зависимостями, скачивание и установка без браузера.
- **План установки.** Перед записью показывается таблица: что, куда и сколько будет скопировано, какие файлы заменяются, что требует ручной установки.
- **Резервные копии и откат.** Заменённые файлы сохраняются, новые файлы и созданные папки удаляются при откате.
- **Мои моды.** Вкладка со всем, что установлено через установщик: моды сгруппированы по названию и сессии установки, показаны дата, количество файлов, размер и число замен. Кнопка «Удалить» возвращает заменённые файлы из резервной копии и удаляет добавленные; файлы, которые позже перезаписала другая установка, не трогаются.
- **Тёмный интерфейс** с русской локализацией.

## Как пользоваться

1. Запустите `GTAModInstaller.exe`.
2. Укажите папку GTA V (кнопка «Сменить» вверху) — установщик попробует найти игру автоматически.
3. Перетащите папку мода или архив в зону загрузки. Можно добавить несколько модов сразу.
4. Дождитесь анализа и проверьте план установки. Галочками можно отключить отдельные файлы, зависимости подключаются отдельно.
5. Нажмите «Установить». После завершения можно открыть папку игры, посмотреть журнал или доустановить недостающие зависимости по предложению установщика.
6. Откройте «Мои моды», чтобы увидеть установленное и удалить отдельный мод. Удаление возвращает заменённые файлы и убирает добавленные; если мод ставил зависимости, они останутся отдельными карточками и их можно удалить вручную. Для отката всей сессии откройте «Резервные копии».

**Перед установкой закройте GTA V.** Папка `Program Files` может требовать запуска от имени администратора.

## Форматы и ограничения

- Поддерживаются ZIP, RAR, 7Z, TAR, TAR.GZ, TGZ, GZ, BZ2, XZ, LZMA, OIV.
- Для RAR и 7Z нужен установленный 7-Zip (или WinRAR); установщик находит их автоматически. ZIP и TAR распаковываются встроенными средствами.
- Моды, изменяющие RPF-архивы, add-on DLC и `dlclist.xml`, требуют OpenIV. Установщик покажет это в плане и предупреждениях, но не будет редактировать RPF сам.
- LML, OpenIV и Gameconfig устанавливаются вручную: приложение даёт ссылку на официальную страницу.
- Исполняемые файлы (`.exe`, `.msi`, `.bat`, `.cmd`, `.ps1` и другие) **никогда не запускаются и не копируются автоматически**. Они попадают в раздел ручной установки.
- Если назначение файла определить нельзя, он также остаётся в ручном списке — ничего не записывается наугад.
- Моды и компоненты принадлежат их авторам. Используйте на свой риск и сохраняйте резервные копии важных файлов.

## Безопасность

- Скачивание разрешено только с GTA5-Mods.com, GitHub и dev-c.com; сторонние хосты блокируются.
- Проверяется сигнатура скачанного архива, HTML-подмена отклоняется.
- Пути из архивов и плана очищаются: обход каталога (`..`), абсолютные пути и буквы дисков не допускаются.
- Ни один скачанный установщик не запускается.
- Перед записью всегда требуется подтверждение плана; по умолчанию включены резервные копии.
- Установщик не запускает игру и не изменяет её исполняемые файлы.

## Где хранятся данные

`%LOCALAPPDATA%\GTAModInstaller`:

- `backups` — сессии установки, резервные копии и манифесты отката;
- `downloads` — скачанные архивы;
- `cache` — временная распаковка и обложки;
- `logs` — журналы;
- `config.json` — настройки и путь к игре.

## Сборка EXE

Требования: Windows 10/11 x64, Python 3.11+ (проверено на 3.14), 7-Zip, интернет для установки зависимостей.

```bat
python -m pip install -r requirements.txt
python -m PyInstaller --noconfirm GTAModInstaller.spec
python tools\make_sfx.py
```

Готовый файл: `dist\GTAModInstaller.exe` (~21 МБ).

Это самораспаковывающийся exe: при запуске он распаковывает приложение во временную папку, запускает его и удаляет файлы после выхода. Аргументы командной строки, включая перетаскивание архивов на exe, передаются приложению.

Из сборки исключены неиспользуемые компоненты Qt (Quick/Qml, Pdf, Network, software OpenGL, переводы) и лишние копии OpenSSL — поэтому файл помещается в лимит GitHub.

Если 7-Zip установлен в нестандартное место, укажите путь к `7z.exe` в переменной `SEVENZIP`.

Или просто запустите `build.bat` — он установит зависимости и соберёт exe.

### Самопроверка

```bat
python main.py --selftest --selftest-file selftest.txt
dist\GTAModInstaller.exe --selftest --selftest-file selftest-exe.txt
```

Самопроверка работает без интернета: распаковка, анализ, установка, резервные копии, откат, список установленных модов и удаление отдельного мода, OIV, парсинг каталога и защита от опасных путей.

### Параметры запуска

- `--game "D:\Games\Grand Theft Auto V"` — игра на один запуск, путь не сохраняется;
- `--page install|mods|online|deps|backups|log` — открыть раздел;
- пути к папкам или архивам после параметров — сразу добавить их в очередь.
